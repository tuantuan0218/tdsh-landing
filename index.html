Features

为什么选 TDSH

把 DeepSeek Harness 的完整能力带进一个原生桌面窗口，既有浏览器的灵活性，又有桌面应用的顺滑。

🔄

一键自动更新

检测到新版本即弹出确认，后台下载显示进度条，下载完成后自动安装替换，无需手动折腾。

⏳

agent-loop 无限续跑

删除 autoContinued 守卫，模型永不 yield —— 目标完成自动派生下一个，长任务一路跑到底。

💾

磁盘友善

所有数据落盘在应用目录，不写系统盘，长时间运行也不怕 C 盘爆掉。

🔗

attach-or-spawn

检测本地 dsh web 是否已运行：已运行直接开窗复用，否则自动拉起新实例，绝不重复占用端口。

🐋

DeepSeek 鲸鱼闪屏

启动时显示官方鲸鱼 Logo 与「探索未至之境」动画，窗口加载完成后自动关闭。

🔒

单实例锁

防止重复启动；关闭窗口自动回收子进程，干净退出不留后台残留。

⚡ 关键能力：agent-loop 无限自动续跑

模型完成一个目标后不会停下，而是自动进入下一轮 —— 一个真正无人值守、持续产出的 agent。

目标完成 → complete_goal → goal-complete-inject → MCTS → 新目标 → 循环

⚠️ 该补丁不在 TDSH 安装包内，需手动应用。备份位于仓库 harness-patches/agent-loop/。
